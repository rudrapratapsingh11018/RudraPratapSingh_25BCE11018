# Live Polling App

A real-time polling application where an admin creates a poll and users join using a room code to vote.

## Progress

- Admin page UI created (question + options)
- Added landing page for joining poll and admin navigation
- Basic project structure set up
 - Styling implemented for layout and components
- Backend initialized using Express and Socket.io

## Tech Stack

- HTML, CSS, JavaScript
- Node.js (planned)
- Socket.io (planned)
- Express

## How to Run

1. Clone the repository  
2. Install dependencies  
   npm install  
3. Start the server  
   node server.js  
4. Open in browser:  
   - Admin: /admin.html  
   - Participant: /vote.html
